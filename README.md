# TON Wallet Balance Checker + Telegram Mini App

Live Demo → https://ton-wallet-checker.vercel.app

## امکانات
- وارد کردن هر آدرس TON → نمایش فوری بالانس
- تولید خودکار QR کد
- اتصال مستقیم والت با TON Connect
- کاملاً آماده استفاده به عنوان تلگرام مینی‌اپ
- بدون بک‌اند – ۱۰۰٪ کلاینت‌ساید

## تکنولوژی‌ها
React + Vite · TON Connect · toncenter.com API · QRCode.js
